# 3D 打印完整工作流

本技能依据用户于 2026-10-17 确定的六步流程及已接受的补充项整理。用户选择本技能后，按此流程开展对应 3D 打印建模任务；当前任务的新明确指示优先。继续项目时核对实际文件和已有确认，从有效阶段恢复。

使用本技能时告知用户。读取可用的个人知识库入口和适用项目规则；未配置个人知识库时依据当前需求工作，不假装读过。运行脚本前阅读 [本地操作](references/local-operations.md)，配置本机路径。逐步详细注解见 [流程注解](references/workflow-notes.md)。

## 步骤 1：用户提出需求

记录原始需求、用途、环境、参考图、配件与已有项目。先了解目的，不擅自补齐关键尺寸或认定历史设备仍在使用。

**注解：** 本阶段产物是需求记录，不是已批准的模型；可初始化项目模板，但不能据此开始实际建模。

## 步骤 2：根据需求选择建模软件

精确尺寸、机械结构和装配选 Fusion 360；雕刻、艺术造型选 Blender。用户指定时按指定执行。优先对应 MCP；连接失败先尝试恢复，无法恢复则说明，不自行更换其他建模库。专项任务按用户现有专项规则执行。

**注解：** 先解释选择理由。端口监听不等于 MCP 可用，必须取得实际软件响应。

## 步骤 3：确定尺寸、细节和修改要求

与用户确认外观、具体尺寸及基准、用途、强度、拆件、装配关系、公差与配合间隙；同时确定打印机、喷嘴、耗材、多色/多材料、热床、表面效果及时间/耗材优先级。记录修改，只问尚缺的信息。

**注解：** 尽早确认打印条件，避免建模后才发现超出打印空间或无法合理支撑；不把演示设备作为用户默认设备。

## 步骤 4：生成 3D 效果图，确认后建模

使用可用图像生成工具生成效果图并保存、展示；根据反馈调整再确认。`submit design` 同时登记需求文档和效果图。只有用户明确同意当前版本，才记录 `confirm design` 并开始建模。

**注解：** 这是第一个确认节点。效果图仅表达外观方向，不证明实体已建好或结构可以打印。没有用户答复不能自动继续。

## 步骤 5：完成模型、请用户确认，再导入切片

在选定软件中通过 MCP 建模并保留源文件。检查尺寸/单位、实体和网格完整性、法线、壁厚、组件、干涉、配合间隙；关键卡扣/插接先做试片。`mesh-check` 的基础结果必须与 CAD 尺寸核对，未覆盖的自相交、壁厚、配合另行检查。

展示实际 CAD/网格截图或可旋转预览及关键尺寸。用户提出修改时修改、复查、重新展示。`submit model` 登记源文件、STL、实际截图和当前 STL 的检查报告；用户同意后才 `confirm model`，再 `open-bambu`。

**注解：** 这是第二个确认节点。生成效果图不能代替真实模型预览；软件检查、实物打印、装配验证分别记录。

## 步骤 6：按需求调参并检查支撑和打印质量

Bambu Studio 为主，OrcaSlicer 仅备用，未经用户选择不切换。先核对实际项目、设备、喷嘴、热床、耗材、工艺及用户已选参数，再调整朝向、层高、壁数、填充、支撑、brim 和材料映射。

检查实际切片预览，填写 `05-检查/切片审查.md`：支撑覆盖与稳定性、拆除路径、工具空间、封闭腔体支撑、孔道堵塞、支撑界面与间距；首层小岛与接触面积；悬空、桥接跨度及落点；薄壁/细节消失；细高件和窄底件稳定性；排布碰撞、翘边与收缩；多材料界面、冲刷和擦料塔。

保存关键层截图或层号。发现问题调整后重新切片检查。**需要改模型结构/尺寸时回到模型确认；需求或外观方向变化时回到效果图方案确认。**

**注解：** 切片成功仅说明生成了路径，不代表支撑易拆、不会翘边或实物必然成功。预览能力不足时明确记录未验证项，不能把清单自动标为通过。

## 补充环节 7：切片最终确认

展示摆放、支撑、关键层、预计时间与模型/支撑/冲刷耗材，说明剩余风险和取舍。`submit slice` 提交已切片 3MF、填写完成的审查文档、预览及报告；用户同意后 `confirm slice`。

**注解：** 第三个确认节点。CLI 可以读取已配置的 Bambu 3MF 切片，但不能擅自替用户选择打印参数，参数调整后需要再次审查。

## 补充环节 8：交付、归档和实物反馈

全部确认仍有效后 `package`，包含可编辑源文件、打印模型、Bambu 工程、已切片文件、参数、预览、检查、哈希与说明。每个模型独立文件夹；保存路径按当前用户配置和专项偏好执行，不移动既有文件。

记录实物首层、翘边、支撑拆除、表面、尺寸、试片与装配反馈后修订。发送到打印机、加热或启动打印需要用户另行明确授权；本技能没有打印机控制命令。

**注解：** 归档保留可复现证据，实物反馈才可支持相应实物结论。

## 执行边界

- 三个阶段标识是 `design`、`model`、`slice`，确认绑定文件哈希；上游变化使下游失效，恢复前先 `status`。
- `confirm` 仅记录真实用户答复。工具无法鉴别文本是否真实，代理不能伪造同意，也不能把本技能安装授权当作模型确认。
- 不覆盖用户源文件/预设，不关闭未保存文档，不静默修复网格。
- 自动化只覆盖确定性的本机操作；建模质量、支撑可拆和翘边风险需结合实际软件、预览和使用条件判断。
